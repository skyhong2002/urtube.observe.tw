# PR #93 前端與品質稽核整合

2026-10-22 以目前 `main` 整合原 2026-09-19 稽核分支仍有價值的變更。保留後續新增的引導流程、分享預覽與設定頁；新帳號維持私人、探索關閉，預覽與匯入不會開啟分享。未變更配對演算法、模型、預算、worker 或已完成的快取。

## 保留的改善

- 註冊 ID 的 HTML pattern 跳脫連字號，相容 Unicode Sets；停用自動大寫與拼字檢查。可用性提示使用狀態區，拒絕的表單顯示已跳脫的錯誤並移動焦點。綁定既有帳號的私人金鑰使用密碼欄位。
- 個人檔案顯示名稱依 Unicode 字元數檢查 1–80 字。只有未儲存變更才註冊離開提醒；還原原值或正常提交會移除提醒，伺服器拒絕的草稿及返回頁面仍受保護。草稿只留在本頁記憶體。
- Takeout 上傳前檢查 ZIP 副檔名及現有 100 MiB 限制，顯示處理狀態並防止重複提交；返回頁面恢復操作。狀態區位於忙碌表單之外，避免輔助技術延後宣告進度；伺服器仍獨立驗證檔案。
- 範圍切換請求等待 15 秒後回到完整頁面導覽；已取消或被新請求取代的導覽不會再改變頁面。
- 共用頁面增加中英文「跳到主要內容」、可聚焦的主內容、原生控制項焦點提示，並在減少動態效果偏好下停用平滑捲動。
- 設定回饋使用實際儲存的公開、探索、匿名統計選項，展開原區塊並聚焦狀態。網址參數只選擇提示種類，不能提供設定值或觸發分享。路由整合需保留既有驗證與設定寫入。
- 新增每週 npm、Python、GitHub Actions 的 Dependabot 更新設定，不啟用自動合併。沿用 `main` 已存在的 security:audit 步驟，只補上完整 Git 歷史供掃描。

## 驗證範圍

回歸涵蓋草稿變更／還原／取消提交／正常提交／返回、Unicode 名稱、惡意表單值跳脫、檔案驗證／重複提交／返回、設定值與焦點、範圍切換逾時／取消，以及目前的 onboarding、分享預覽與導覽流程。測試使用虛構資料及記憶體或暫存資料庫。

原 PR 的測試數字、瀏覽器抽查、正式站 GET 與套件告警紀錄屬於舊版本，未作為本次整合的驗證結果沿用。完整整合以主分支測試與 CI 結果為準。

瀏覽器離開提醒受使用者互動及作業系統限制，無法保證攔截程序直接關閉。本次回歸不等於完整 WCAG 認證、正式 OAuth 登入測試或滲透測試。
